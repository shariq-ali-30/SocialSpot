# SocialSpot

## About the Project

SocialSpot is a social media web application built with React where users can create, share, edit, delete, and interact with posts. It includes email/password and Google authentication, user profile information, image uploads, real-time posts powered by Firebase Firestore, likes, comments, and a dedicated section for managing personal posts.

## Technologies Used

- React
- JavaScript
- HTML5
- Tailwind CSS
- Vite
- Firebase Authentication
- Cloud Firestore
- React Router DOM
- Cloudinary
- Phosphor Icons

## Features

### Authentication & Profile
- User registration with email and password
- User login with email and password
- Google authentication
- User logout functionality
- User profile information and profile images
- Login-required prompts for restricted actions

### Posts
- Create posts with an optional title and description
- Upload images with posts
- Image hosting using Cloudinary
- View posts in real time using Firebase Firestore
- Edit your own posts
- Delete your own posts with a confirmation dialog
- Display post author information and profile images
- Display relative post creation time
- Like and unlike posts
- Display total likes on posts
- View your own posts in the **My Posts** section

### Comments
- Add comments to posts
- Expand or collapse a post's comments section
- View comments with author names, profile images, and relative timestamps
- Delete your own comments

### User Experience & Interface
- Responsive design for different screen sizes
- Mobile-friendly navigation
- Loading indicators while posts are being fetched
- Empty states when no posts are available
- Reusable React components
- Interactive modals for creating, editing, and deleting posts
