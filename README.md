# SocialSpot

## About The Project

SocialSpot is a social media web application built with React where users can create, share, edit, delete, and interact with posts.

The application includes user authentication, Google login, profile information, image uploads, real-time posts using Firebase Firestore, likes, and a separate section for managing personal posts.

## Technologies Used

- React.js
- JavaScript
- HTML5
- Tailwind CSS
- Vite
- Firebase Authentication
- Firebase Firestore
- React Router DOM
- Cloudinary
- Local Storage
- Phosphor Icons

## Features

- User registration with email and password
- User login with email and password
- Google authentication
- User logout functionality
- User session persistence using Local Storage
- User profile information
- Real-time posts using Firebase Firestore
- Create new posts
- Add post title and description
- Upload images with posts
- Image hosting using Cloudinary
- Edit your own posts
- Delete your own posts
- Like and unlike posts
- Display total likes on posts
- Display post author information
- Display post creation date and time
- My Posts section to view your own posts
- Login-required modal for restricted actions
- Post loading state
- Empty state when there are no posts
- Responsive design
- Mobile-friendly navigation
- Reusable React components
- Protected post editing and deletion for post authors
